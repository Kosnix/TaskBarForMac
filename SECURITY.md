# Security Policy

## Supported Versions

Only the latest released version of TaskBarForMac is supported with security fixes.

## Reporting a Vulnerability

This is a personal, independently maintained project. If you find a security issue, please report it privately rather than opening a public issue:

- Open a [GitHub Security Advisory](https://github.com/Kosnix/TaskBarForMac/security/advisories/new) for this repository, or
- Open an issue without including exploit details, and a way to reach you privately will be provided.

Please include steps to reproduce, the affected version, and your macOS version. There's no fixed response-time guarantee, but reports will be acknowledged and addressed as soon as possible.
